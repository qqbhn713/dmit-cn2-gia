## CN2 GIA到底是什么，凭什么这么贵

先搞清楚概念，不然花了钱还不知道买的是什么。

中国电信的网络骨干大概分三档：

- **163骨干网**：最普通，走的是AS4134，全球覆盖广但优化差，晚高峰丢包严重，延迟飘忽不定。大多数便宜VPS用的就是这个。
- **CN2 GT**（Global Transit）：部分路径走CN2，进中国大陆后还是得回到163。算是半优化，比163好一点，但不稳。
- **CN2 GIA**（Global Internet Access）：全程走电信CN2骨干，进出中国大陆双向都走优化路由，丢包少、延迟低、稳定性强。这是电信给企业级客户用的线路，自然贵。

用一个不太严谨的类比：163是普通公路，CN2 GT是高速公路但偶尔有匝道要绕回普通路，CN2 GIA是直达高速，全程不堵车。

晚上8点到11点，是CN2 GIA和163差距最明显的时候。前者延迟可能150ms出头，后者可能突破300ms甚至丢包20%+。如果你的使用场景涉及远程连接、视频流、或者需要稳定低延迟的业务，这个差距直接决定能不能用。

## CN2 GIA的几个常见误区

在做选择之前，有几个坑提前说一下，避免买了之后后悔。

**误区一：CN2 GIA就代表完美网络**

CN2 GIA是线路层面的优化，不是魔法。如果服务器硬件差、带宽超卖严重，CN2 GIA线路也救不了。选服务商要看整体配置，不只是线路标签。

**误区二：越便宜越不稳定**

价格和稳定性不是线性关系。DMIT的$36.9/年套餐走的是和高价套餐一样的CN2 GIA线路，差的只是配置（内存、带宽、流量）。如果你的负载低，便宜套餐同样稳。

**误区三：香港一定比洛杉矶好**

这取决于你的业务性质。如果面向全球用户，洛杉矶地理位置更中心，到欧美延迟更低。如果主要服务中国大陆用户，香港确实更有优势。两者没有绝对优劣，看场景。

**误区四：流量越多越好**

流量用不完等于白花钱。普通博客加上一些图片，每月几十G流量就够了。500G/月已经是非常充裕的量，除非你在跑流媒体或者大流量下载站，不然不需要盯着流量数字焦虑。
